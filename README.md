# secure_vault

A new Flutter project.

Vault data is encrypted and stored locally on the device where the vault is
created. Windows and Android use separate app storage; this app does not sync
credentials between devices.

The vault remains unlocked when you switch away and return within the existing
three-minute inactivity timeout. Secure notes support bold text and heading
formatting, and attached files are stored inside the encrypted vault.
Choose a username when creating the vault; it is encrypted with your data and
required along with the vault password to unlock it.
The welcome screen leads into vault setup or sign-in. You can add a profile
photo from the profile button; it is stored inside the encrypted vault.
